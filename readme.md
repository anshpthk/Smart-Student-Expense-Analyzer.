Smart Student Expense Analyzer

A simple command-line expense tracker built in Python. This is my final project submission for the Python Essentials course on the Vityarthi portal. I made it to help college students easily track their daily spending, manage monthly budgets, and see where their money is actually going.

What it does:
- Budget Setup: Allows you to set a monthly budget.
- Expense Logging: Add daily expenses under categories like Food, Transport, Academics, Hostel, etc.
- Auto-Save: Saves all data to a local text file so you don't lose your records when you close the app.
- Summary Dashboard: Shows recent transactions, total spent per category, and warns you if you are going over budget.

Syllabus Modules Used:
This project uses the concepts we learned throughout the course:
- Module 12 (OOP): Used a class called Expense to create individual expense objects.
- Module 7 (Data Structures): Used Lists to store all the expenses and Dictionaries to calculate the total spent per category.
- Module 8 (Control Flow): Used while loops for the main menu and if/elif statements for budget warnings.
- Modules 4 & 6 (I/O & Type Conversion): Used input/print functions and converted string inputs into floats for the money calculations.

How to run it:
1. Make sure Python is installed on your computer.
2. Open your terminal in the folder where you saved these project files.
3. Run the command: python main.py
