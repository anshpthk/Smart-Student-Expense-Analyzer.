# Project Statement: Smart Student Expense Analyzer

## Problem Statement
College students often struggle to track their daily expenses and manage their monthly allowances effectively. Keeping manual records is tedious, and relying on memory often leads to overspending and financial stress before the month ends.

## Scope of the Project
This project is a command-line utility built in Python that allows students to log daily transactions, categorize them into student-specific buckets (Food, Transport, Academics, Hostel, Misc), and compare total expenditures against a user-defined monthly budget. The application uses local file storage to ensure data persists between sessions, keeping the focus on core Python fundamentals like Object-Oriented Programming, Data Structures, and Control Flow.

## Target Users
* College and university students managing personal monthly allowances.
* Hostel residents who need to track shared or individual daily expenses.
* Beginners looking for a straightforward, offline budgeting tool without complex database setups.

## High-Level Features
* **Dynamic Budget Allocation:** Users can set and update a custom monthly financial limit.
* **Categorized Expense Logging:** Add expenses with detailed descriptions and automated date fetching.
* **Persistent Local Storage:** Automatic saving and loading of user data to a local text file.
* **Real-Time Summary Dashboard:** View recent transactions, a category-wise breakdown of spending, and interactive warnings if the budget limit is approaching or exceeded.
